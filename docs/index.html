Antes de cada sesión

Comprobar el entorno

Un script que indica si tu equipo tiene las herramientas del curso y si tu copia del material coincide con la última versión publicada (s1 hasta la sesión que vas a empezar, y entorno/). Se ejecuta después de hacer el git pull ó make -C entorno actualizar. Si falta algo, te dice qué y cómo arreglarlo. En una terminal del equipo (en Windows, la de Ubuntu de WSL2): 

curl -fsSL https://raw.githubusercontent.com/dsevilla/tcdm-public/26-27/entorno/comprobar-entorno.sh | bash -s s3

Cambia s3 por la sesión que vas a empezar. Cuando tengas el material actualizado, también puedes ejecutarlo desde la raíz de tu copia con bash entorno/comprobar-entorno.sh s3.

Ver el script
